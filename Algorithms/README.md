# 🧩 Algorithms Collection

## 📌 Aim
This folder contains Python programs that solve small, logic‑based problems. Each program demonstrates conditional statements, loops, and arithmetic operations — useful for placements and practice.

---

## 📝 Problems Included

### 1. Attendance Percentage Calculator (`AttPerCal.py`)
- **Problem:** Calculate attendance percentage based on total working days (22) and present days.  
- **Condition:** If attendance < 75%, print warning.  
- **Sample Output:**  
Enter the present days: 15
Warning, Your attendance is below 75 %

---

### 2. Coin Change Problem (`CoinChange.py`)
- **Problem:** Calculate minimum number of coins required for a given amount.  
- **Algorithm:**  
- Sort coins in descending order.  
- Use greedy approach to subtract coins until amount = 0.  
- **Sample Output:**  
[100, 100, 100, 100, 100, 100, 50]
7

---

### 3. Demand Pricing (`DemandPricing.py`)
- **Problem:** Adjust price based on demand and membership level.  
- **Condition:**  
- High demand + Normal membership → 20% surge fee.  
- **Sample Output:**  
Enter the price: 1000
Demand levels: High, Medium, Low
Enter the demand level: High
Membership levels: Normal, Premium
Enter the membership: Normal
Final price: 1200

---

### 4. Nearest Driver (`DisOfCusDriv.py`)
- **Problem:** Find the closest driver to a customer using distance formula.  
- **Condition:** Print driver index and distance.  
- **Sample Output:**  
Customer location: 2 3
Driver details:
Enter the available number of drivers: 2
Enter driver location (x y): 1 1
Enter driver location (x y): 4 4
The closest driver is Driver 1 with distance 2.24

---

### 5. Two Sum (`TwoSum.py`)
- **Problem:** Find pairs of numbers in a list that add up to a target value.  
- **Algorithm:**  
- Use two nested loops to check sums.  
- Append valid pairs to result list.  
- **Sample Output:**  
[(4, 9), (5, 8), (6, 7)]
